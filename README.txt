C++ VISION — HỌC CODE BẰNG MẮT

CÁCH DÙNG
1. Giải nén ZIP, giữ index.html, style.css, lessons.js, simulator.js, app.js cùng thư mục.
2. Mở index.html bằng trình duyệt trên máy tính hoặc điện thoại.
3. Chọn bài, dán hoặc sửa mã C++, nhập dữ liệu kiểm thử (stdin).
4. Nhấn “Phân tích & mô phỏng”, rồi chọn “Từng bước” hoặc “Phát”.
5. Di chuột vào từng dòng hoặc bấm số dòng để xem giải thích.
6. Chuyển giao diện bằng nút Giao diện; tiến độ được lưu trên thiết bị.

TRIỂN KHAI GITHUB PAGES
- Tải 5 tệp trên vào thư mục gốc của GitHub repository.
- Trong Settings > Pages, chọn Deploy from a branch, branch main, /(root).
- Đợi GitHub Pages xuất bản rồi truy cập đường dẫn do GitHub cung cấp.

GIỚI HẠN
- Công cụ là trình mô phỏng giáo dục chạy nội bộ bằng JavaScript, không phải trình biên dịch C++ thực.
- Hỗ trợ nhập/xuất, số, chuỗi, mảng, vector, if/else, for/while, hàm, đệ quy và vài thao tác STL.
- Những ví dụ dùng con trỏ, class, map và cú pháp C++ ngoài phạm vi sẽ báo không hỗ trợ.
- Một câu lệnh trên một dòng giúp phần giải thích dễ theo dõi nhất.
- Không dùng ứng dụng để kiểm chứng chính xác hành vi C++ phụ thuộc compiler, tối ưu hóa hay bộ nhớ.
