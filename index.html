Chào mừng đến C++ Vision ✨

Trang web giúp bạn nhìn thấy code thực thi thay vì chỉ đọc lý thuyết.

  1. Chọn bài học ở thanh bên hoặc dán code C++ của bạn vào ô soạn thảo.
  2. Nhập số kiểm thử ở mục Dữ liệu nhập, ví dụ 5 10.
  3. Bấm Phân tích & mô phỏng, rồi bấm Từng bước để thấy giá trị biến và đầu ra thay đổi.
  4. Di chuột qua một dòng hoặc chạm vào số dòng trên điện thoại để xem giải thích của dòng đó.

Lưu ý: Đây là trình mô phỏng để học, không phải compiler C++ thật. Mỗi câu lệnh nên để trên một dòng. Các cú pháp chưa hỗ trợ sẽ báo lỗi, không tự đoán đầu ra.
